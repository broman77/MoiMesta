# Мои места — Android v3.0

> **Исправление сборки GitHub Actions:** workflow теперь явно устанавливает Android SDK через `android-actions/setup-android@v4`, поэтому `sdkmanager` доступен до установки API 37 и Build Tools 36.0.0.


Мобильное приложение-карта для личного списка мест.

## Что есть в версии 3.0

- интерактивная карта с масштабированием и маркерами;
- список мест, поиск и фильтры;
- добавление и удаление своих мест;
- выбор точки прямо на карте;
- отметка «Посещено»;
- личная оценка от 1 до 5 звёзд;
- комментарии к каждому месту;
- фотографии мест из Wikimedia Commons;
- статистика;
- светлая, тёмная и системная тема;
- экспорт всей базы в Excel-совместимый файл `.xls`;
- резервная копия в `.json`;
- импорт резервной копии на другом Android-телефоне;
- при переносе восстанавливаются места, координаты, категории, посещения, рейтинги, комментарии, тема и сохранённые ссылки на фото.

## Как собрать APK через GitHub

1. Создайте новый репозиторий GitHub.
2. Распакуйте этот ZIP.
3. Загрузите **всё содержимое** распакованной папки в корень репозитория.
4. Проверьте, что файл `.github/workflows/build-apk.yml` присутствует в репозитории.
5. Откройте вкладку **Actions**.
6. Выберите **Build Android APK**.
7. Нажмите **Run workflow**, если сборка не запустилась автоматически.
8. После зелёной галочки откройте завершившийся запуск.
9. В разделе **Artifacts** скачайте `MoiMesta-APK`.
10. Внутри будет `MoiMesta-v3.apk`.

## Перенос на новый телефон

На старом телефоне:

1. Откройте **Профиль → Экспорт и перенос**.
2. Нажмите **Скачать резервную копию**.
3. Сохраните файл `MoiMesta-backup-ГГГГ-ММ-ДД.json` в «Файлы», Google Drive или другое доступное место.

На новом телефоне:

1. Установите приложение.
2. Откройте **Профиль → Экспорт и перенос**.
3. Нажмите **Загрузить резервную копию**.
4. Выберите сохранённый `.json`.
5. Подтвердите замену текущей базы.

После импорта места появятся автоматически вместе со статусами посещения, оценками и комментариями.

## Excel

Кнопка **Выгрузить в Excel** создаёт Excel-совместимый `.xls` с колонками: название, категория, адрес, посещение, оценка, комментарий, координаты и дата последнего изменения.

## Техническая информация

- package: `com.ivan.moimesta`
- minSdk: 24
- targetSdk / compileSdk: 37
- Java: 17
- versionCode: 3
- versionName: 3.0.0
- данные приложения хранятся локально в WebView Local Storage;
- экспорт и импорт используют стандартный Android Storage Access Framework, поэтому разрешение на полный доступ к файлам не требуется.
